# EduManager (AcademyOS) — Live Demo

**▶ Try it: https://adam-1897.github.io/edumanager/**

School management web app for tutoring centers and small schools. It tracks students, teachers, classes, attendance, payments, expenses and events, with a live financial dashboard.

## What it does

- **Students:** profiles, parent contacts, attendance percentage and outstanding balance
- **Teachers:** salaries, hire dates and how many classes each one teaches
- **Classes:** schedule, room, monthly fee and assigned teacher
- **Attendance:** a monthly sheet where each day is marked Present, Absent or Excused
- **Payments:** tuition by month, payment method, and who still owes money
- **Expenses and events:** costs by category, and each event's revenue, cost and profit
- **Dashboard:** this month's revenue, expenses including salaries, net profit and margin, all updating as data changes
- **Accounts:** sign in / sign up, an admin-only Users page, and password changes
- **Notes and to-dos:** sticky notes and a task list with priorities and due dates

## About this demo

This repository contains only a self-contained demo build (`index.html`). It runs entirely in your browser with sample data and no server: anything you change is saved in your browser only.

Sign in with **admin / admin123**, or create your own account on the Sign up tab.

## Tech stack (full application)

- **Backend:** Java 23, Spring Boot 3, Spring Security with JWT, Spring Data JPA / Hibernate
- **Database:** MySQL 8
- **Frontend:** React 18, Vite

The full source code is private.
